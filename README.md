# Amber's Hobby List

A short list of a few hobbies that I enjoy doing on a regular basis. Click the "My Hobbies" or "hobbies" links and it will populate the list.

## Built With

- Python
- Flask

## Running Locally

1. `pip install flask`
2. `python app.py`
3. Open `http://127.0.0.1:5000` in your browser
